🌟 NammaSIT
A simple and smart student companion for SIT

NammaSIT is a unified ai powered platform that brings all essential student-related information into one clean and accessible website. It helps students quickly access notes, PYQs, campus details, clubs, sports info, marketplace features, and personalized ML-based suggestions — all in one place.

🚀 Features

📚 Notes & PYQs – Subject-wise notes and previous year papers with a clean PDF viewer.
🤖 ML Suggestions – Users enter interests and receive personalized recommendations.
🏫 Campus Info – Health Centre, Gym, and campus locations with images.
🛒 Buy & Sell – Simple marketplace for students.
🔍 Lost & Found – Report lost/found items easily.
🏀 Clubs & Sports – Basic details of activities and clubs.
🎉 Student Posts & Memes – Fun community section.
📊 LeetCode Leaderboard – Inspires coding culture.

🛠 Tech Stack

Frontend: React (Vite), HTML, CSS, JavaScript
Backend: Node.js, Express.js, MongoDB
Machine Learning: Python, NumPy, Scikit-learn

📥 Setup Instructions
1️⃣ Clone the repository
git clone <repo-link>
cd SIT4U

2️⃣ Frontend Setup
cd frontend
npm install
npm run dev

3️⃣ Backend Setup
cd backend
npm install

Create a .env file:
MONGO_URI=your_mongodb_url
PORT=5000

Run backend:
node server.js

4️⃣ ML Model Setup

Install required Python libraries:
pip install numpy
pip install scikit-learn

Run model (if needed):
python model.py
